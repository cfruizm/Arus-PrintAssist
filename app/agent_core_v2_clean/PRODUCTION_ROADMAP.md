# Production Roadmap

1. **3D.2 Documental checkpoint**: accurate limitation semantics and short regression campaign.
2. **4A Modular escalation**: structured incident collection and clean lifecycle.
3. **4B Multi-turn troubleshooting**: one action at a time, observed results, no repeated failed steps, escalation handoff.
4. **4C Production observability**: compact turn events for route, intent, evidence, sources, tokens, latency, failures and escalation state.
5. **4D Hardening**: access controls, log sanitization, secrets, failure modes, regression gates and rollback guide.
6. **5A Controlled pilot**: limited users, success metrics, defect triage and monitored rollback.
7. **5B Production candidate**: pilot corrections and explicit release approval.
